# XXD Panel 086 原文プロンプト · 日本語読解訳

アップロードした写真を1枚ずつ、独立した上質なデザインポスターにしてください。複数画像を連結せず、各写真を個別に出力します。全体は3:4の縦構図とし、上下2領域の高さを厳密に1:1、各50%にします。

上半分には元写真を残し、主体の同一性、構造、姿勢、実在感のある質感、自然な光と影、元の色彩の雰囲気を保ちます。調整は控えめで上質なカラーグレーディングに限り、アート雑誌、独立系出版物、展覧会写真のような質感にします。画角に合わせて周囲の環境を自然に拡張しても構いませんが、主体を引き伸ばしたり、歪めたり、改変したりしてはいけません。

下半分では、まず写真を成立させている**主体、輪郭、姿勢、方向、空間関係、物語の焦点**を分析し、最重要の視覚情報を3〜5個だけ残して、ミッドセンチュリー・モダニズムの気質を持つ**限定色シルクスクリーン版画風テクスチャイラスト**へ再構成します。すべての要素を均等に残したり、元の場面を完全に描いたりしません。「何が最も見る価値があり、何が消えてよいか」を判断し、高度に要約しても元の対象がひと目で分かり、元写真より明確な視覚秩序を持たせます。

構図では**大面積の余白を能動的なデザイン言語**として使います。機械的に中央へ置くのではなく、主体の向き、動きの傾向、視覚的重量、元写真で最も意味のある空間関係から着地点を定め、その後で紙面を組みます。主体は偏らせ、縮小し、部分的に裁ち落とし、画面端へ寄せてもよく、広い空白との間に尺度の緊張を作ります。余白には空、距離、光、海面、地面、沈黙、時間感覚を担わせます。非対称の均衡、正負形、視覚軸、疎密リズム、高低のずれで上質なレイアウトを作り、常に**一つの明確な焦点、一つの主要方向、一片の意味ある空白**を保ちます。

主体をシルエット、幾何形、簡潔な色面、少数の重要構造で作り直し、環境には物語に本当に参加する少数の形だけを残します。**Risograph / Screen Print–inspired textured illustration** の言語を用い、dry-brush、brayer texture、dragged ink、broken ink、uneven ink coverage によって横方向の引きずり墨、かすれ、断墨、粗いインク質感を作ります。一つまたは少数の幾何円、色帯、弧、切面を加え、有機的な印刷肌理と秩序の対比を作っても構いませんが、装飾の堆積にはしません。

上の写真から**最も鮮明で生命力があり、主体の気質を最もよく表す色関係**を抽出し、2〜4色の特色へ圧縮します。元写真の色相の記憶を保ちながら、適度に明度、純度、明瞭さを上げます。一つの鮮明な主色、一つの濃い構造色、一つの淡い紙地色、必要な場合だけごく少量の差し色で階層を作ります。色は明るく、温かく、生命力を持ちながら、版画インクの複合的な色味を保ちます。濁った灰色、モランディ調、蛍光色、安価なキャンディー色、デジタルグラデーションは避けます。

主体分析から得た**感情、動作、場所、方向、比喩**に基づき、少量の短い文字を自由に生成し、言語や固定情報形式は限定しません。**簡潔で抑制され、わずかな活版印刷の誤差とモダニズム書籍の気質を持つ細身書体**を使います。文字は付加的な説明ではなく、主体位置と余白構造に応じて再配置します。広い空白の縁に置く、視覚軸に沿わせる、地平線に揃える、シルエットの縁へ寄せる、ごく小さな組版上の重心を一つ作るなどして、図形と文字がともに画面の均衡を完成させます。

全体は、**意味ある大面積の余白、鮮明な主体、限定特色、シルエット造形、幾何学秩序、ドライブラシの引きずり墨、抑制された図文組版**が一体となる上質な版画ポスターの気質にします。遠くからはまず余白、比率、構図を感じ、近づいて初めて粗いインクと印刷細部に気づくようにします。主体を大きくして画面を埋めること、要素の均等分布、複雑な背景、複数の視覚中心、装飾の堆積、写実絵画、滑らかなベクター、3Dレンダリング、テンプレート式レトロポスターは避けます。
