# XXD Panel 086 원본 프롬프트 · 한국어 읽기 번역

업로드한 사진을 각각 하나의 독립된 고급 디자인 포스터로 제작하세요. 여러 이미지를 이어 붙이지 말고 사진마다 별도로 출력합니다. 전체는 3:4 세로 구도로 구성하며 위아래 두 영역의 높이를 엄격히 1:1로 맞춰 각각 화면의 50%를 차지하게 합니다.

위쪽 절반에는 원본 사진을 유지하고 피사체의 정체성, 구조, 자세, 실제 질감, 자연스러운 빛과 그림자, 원래의 색채 분위기를 보존합니다. 미세하고 고급스러운 색 보정만 적용해 예술 잡지, 독립 출판물, 전시 이미지 같은 질감을 부여합니다. 화면비에 맞추기 위해 주변 환경을 자연스럽게 확장할 수 있지만 피사체를 늘이거나 왜곡하거나 바꾸어서는 안 됩니다.

아래쪽 절반에서는 먼저 사진을 성립시키는 **피사체, 윤곽, 자세, 방향, 공간 관계, 서사 초점**을 분석하고 가장 중요한 시각 정보 3–5개만 남긴 뒤 미드센추리 모더니즘 기질의 **제한색 실크스크린 판화풍 질감 일러스트**로 재구성합니다. 모든 요소를 고르게 남기거나 원래 장면을 완전히 묘사하지 않습니다. “무엇이 가장 볼 가치가 있고 무엇이 사라져도 되는가”를 판단해 피사체를 고도로 요약한 뒤에도 한눈에 알아볼 수 있고 원본보다 더 명확한 시각 질서를 갖추게 합니다.

구도는 **넓은 여백을 능동적 디자인 언어**로 사용합니다. 기계적으로 중앙에 두지 말고 피사체의 방향, 움직임, 시각적 무게, 원본에서 가장 의미 있는 공간 관계에 따라 위치를 먼저 정한 뒤 화면을 조직합니다. 피사체를 치우치게 놓거나 줄이거나 일부 자르거나 화면 가장자리에 가깝게 두어 넓은 빈 공간과 규모 긴장을 만들 수 있습니다. 여백은 하늘, 거리, 빛, 바다, 땅, 침묵, 시간감을 담당합니다. 비대칭 균형, 양형과 음형, 시각축, 밀도 리듬, 높낮이 어긋남으로 고급 레이아웃을 만들고 항상 **하나의 명확한 초점, 하나의 주요 방향, 하나의 의미 있는 여백**을 유지합니다.

피사체는 실루엣, 기하 형태, 간결한 색면, 소수의 핵심 구조로 다시 만들고 환경에는 서사에 실제로 참여하는 소수의 형태만 남깁니다. **Risograph / Screen Print–inspired textured illustration** 언어를 사용하고 dry-brush, brayer texture, dragged ink, broken ink, uneven ink coverage를 통해 가로로 끌린 잉크, 마른 여백, 끊긴 잉크, 거친 안료 질감을 형성합니다. 하나 또는 소수의 기하학적 원, 색 띠, 호, 절단면을 더해 유기적 인쇄 질감과 질서의 대비를 만들 수 있지만 장식 더미가 되어서는 안 됩니다.

위 사진에서 **가장 선명하고 생명력 있으며 피사체의 기질을 가장 잘 대표하는 색 관계**를 추출해 2–4가지 별색으로 압축합니다. 원본 색상의 기억을 유지하면서 밝기, 순도, 선명도를 적당히 높입니다. 하나의 선명한 주색, 하나의 짙은 구조색, 하나의 옅은 종이 바탕색, 필요할 때만 아주 적은 강조색으로 층위를 만듭니다. 색은 밝고 따뜻하고 생명력 있으면서 판화 잉크의 복합 색감을 유지해야 합니다. 탁한 회색, 모란디화, 형광색, 값싼 사탕색, 디지털 그라데이션은 피합니다.

피사체 분석에서 얻은 **감정, 동작, 장소, 방향, 은유**에 따라 소량의 짧은 글자를 자유롭게 생성하고 언어나 고정 정보 유형을 제한하지 않습니다. **간결하고 절제되며 약간의 활자 인쇄 오차와 모더니즘 서적의 기질을 지닌 좁은 서체**를 사용합니다. 글자는 덧붙인 설명이 아니라 피사체 위치와 여백 구조에 따라 다시 조판해야 합니다. 넓은 빈 공간의 가장자리에 누르듯 놓거나 시각축을 따르거나 수평선에 맞추거나 실루엣 가장자리에 붙이거나 아주 작은 조판 무게중심 하나를 형성해 그림과 글자가 함께 화면 균형을 완성하게 합니다.

전체는 **의미 있는 넓은 여백, 선명한 피사체, 제한 별색, 실루엣 조형, 기하 질서, 드라이브러시 끌림 잉크, 절제된 이미지·텍스트 조판**이 함께 이루는 고급 판화 포스터의 기질을 보여야 합니다. 멀리서는 먼저 여백, 비율, 구도를 느끼고 가까이에서야 거친 잉크와 인쇄 세부가 보이게 합니다. 피사체가 너무 커 화면을 채우는 것, 요소의 균등 분포, 복잡한 배경, 여러 시각 중심, 장식 쌓기, 사실적 회화, 매끄러운 벡터, 3D 렌더링, 템플릿식 복고 포스터는 피합니다.
